# Rendering Engine Created Utilizing [D3D12](https://learn.microsoft.com/en-us/windows/win32/direct3d12/directx-12-programming-guide)

## Technologies Used
* C++
* D3D12
* HLSL

## Current Capabilities
* Rasterization with PBR
* Real-time Pathtracing
* Material Creation with Bindless Textures
* Reading in .obj Files
* Perspective and Orthogonal Cameras
* Multi-Frame Synchronization 
* Particle System
* Screen Space Refraction
